# Чулочный клуб · чат с ИИ-агентами

Локальный групповой чат в стиле Telegram. Три независимые ИИ-сессии OpenCode обсуждают тему, видят общую переписку и отвечают друг другу. Владелец и приглашённые друзья тоже могут писать в чат.

**Это исходники приложения, а не готовый облачный сервис.** После скачивания приложение нужно запустить на своём компьютере. GitHub Pages не запускает Node.js-сервер и не заменяет OpenCode.

## Возможности

- Сол — ведущий, Алиса — стилист, Марк — эксперт по комфорту.
- Настоящие ответы подключённой модели, а не заранее записанный сценарий.
- Общая переписка, поиск по сообщениям, индикатор набора текста.
- Кнопки **«СТОП»** и **«Продолжить»** для владельца.
- Друзья входят под своими именами по секретной ссылке-приглашению.
- Гости могут читать и писать, но не могут запускать или останавливать ИИ.
- История сохраняется локально и восстанавливается после перезапуска.
- Нет npm-зависимостей: используются встроенные модули Node.js.

## Что установить

Основная проверенная платформа — **Windows 10/11**.

| Компонент | Для чего нужен |
| --- | --- |
| [Node.js](https://nodejs.org/) **22 или новее** | Запуск приложения. npm устанавливается вместе с Node.js. |
| [OpenCode](https://opencode.ai/) **V2** | Сессии и доступ к текстовой модели. Проверено с OpenCode 2.3.0. |
| Текстовая модель, подключённая в OpenCode | Генерация сообщений агентов. У модели должны быть доступные лимиты. |
| [cloudflared](https://github.com/cloudflare/cloudflared) — необязательно | Временный доступ для друзей через интернет. |

Git не обязателен: можно скачать репозиторий кнопкой **Code → Download ZIP**. Базовый Node.js-сервер не привязан к Windows, но инструкции для туннеля и `.cmd`-файлы рассчитаны на Windows.

## Быстрый запуск

### 1. Скачайте исходники

На странице репозитория нажмите **Code → Download ZIP**, распакуйте архив в обычную папку. Не запускайте приложение прямо из архива.

Либо склонируйте репозиторий через Git:

```powershell
git clone https://github.com/Lireess/stockings-agent-chat.git
cd stockings-agent-chat
```

### 2. Подготовьте OpenCode

Откройте OpenCode и убедитесь, что:

- работает его локальный фоновый сервис;
- подключена текстовая модель;
- у модели не исчерпаны лимиты.

Ключ модели настраивается **в OpenCode**, а не в файлах этого проекта. Бесплатная модель тоже может иметь ограничения.

### 3. Откройте терминал в папке проекта

В Проводнике откройте распакованную папку, в адресной строке введите `powershell` и нажмите Enter. В терминале выполните:

```powershell
node --version
npm --version
npm start
```

**`npm install` не требуется.** Если `node` или `npm` не найдены, установите Node.js с официального сайта и откройте новый терминал.

При запрете PowerShell на запуск `npm.ps1` используйте `npm.cmd start` либо команду без npm:

```powershell
node server.mjs
```

Альтернатива на Windows — двойной клик по `start.cmd`. При ошибке окно останется открытым.

### 4. Откройте чат

Перейдите по адресу:

**http://127.0.0.1:4317**

Нажмите **«Начать разговор»**. Первые ответы могут появиться не сразу: скорость зависит от модели. Чтобы сервер продолжал работать, не закрывайте его терминал.

## Как пользоваться

- **Ваше сообщение:** введите текст внизу и нажмите Enter. Shift + Enter добавляет новую строку.
- **«СТОП»:** прерывает активную генерацию и запрещает следующие ходы агентов.
- **«Продолжить»:** возобновляет обсуждение с сохранённой перепиской.
- **Счётчик `11 / 60`:** агенты дали 11 ответов из 60 за текущий цикл. Сообщения людей не считаются.
- **После 60 ответов:** автоматическая пауза. Следующий цикл запускается кнопкой «Продолжить».
- **Поиск:** поле слева, поиск по тексту и именам.
- **Без ИИ:** вы с другом можете общаться, даже когда агенты остановлены.

Сообщение, отправленное во время генерации, попадёт в контекст **со следующего хода**. Уже начатый ответ оно не меняет.

> Ответы ИИ расходуют лимиты или баланс модели, подключённой в OpenCode. Три участника — это три отдельные сессии, а не обязательно три разные модели. При запуске из OpenCode используется модель запускающей сессии; при отдельном запуске — модель по умолчанию в OpenCode.

## Доступ для друга через интернет

### 1. Установите cloudflared

Не закрывая терминал с основным сервером, откройте **второй терминал в папке проекта** и выполните:

```powershell
npm run setup:share
```

Или без npm:

```powershell
node scripts/install-cloudflared.mjs
```

Скрипт скачает официальный Windows x64 `cloudflared.exe` в папку `tools/` и сверит SHA-256 с данными официального релиза. Администраторские права не требуются, системные настройки и брандмауэр не изменяются.

Можно установить вручную: скачайте `cloudflared-windows-amd64.exe` из [официальных релизов](https://github.com/cloudflare/cloudflared/releases), сверьте его контрольную сумму, переименуйте в `cloudflared.exe` и положите в `tools/`.

### 2. Запустите внешний доступ

В том же втором терминале:

```powershell
npm run share
```

Или `node share.mjs`, либо двойной клик по `share.cmd`.

### 3. Отправьте приглашение

В терминале появится HTTPS-ссылка с частью `#invite=...`. Эта же ссылка сохранится в **`share-link.txt`**.

Отправьте другу **полную ссылку**. Он введёт своё имя и попадёт в ту же переписку. Если страница просит код вручную, он хранится в локальном файле `share-private.json`, в поле `inviteCode`.

**Код создаётся случайно на каждом новом компьютере.** В репозитории нет готовых рабочих кодов. Не отправляйте другу файл `share-private.json` целиком и не публикуйте приглашение.

### Разделение доступа

| Вход | Адрес | Права |
| --- | --- | --- |
| Владелец | `http://127.0.0.1:4317` на компьютере с сервером | Переписка, запуск и остановка ИИ |
| Гость | HTTPS-ссылка с приглашением | Просмотр и отправка сообщений |

Отдельная локальная ссылка — вход владельца; удалённого входа администратора по секретному коду в этой версии нет.

Имя гостя не подтверждает его личность. Гостевая сессия действует 6 часов; после выхода или истечения срока нужно снова открыть исходное приглашение. На узком экране боковая панель может быть скрыта.

### Важные ограничения

- Это **временный туннель**, а не круглосуточный облачный хостинг.
- Компьютер, основной сервер и туннель должны оставаться включёнными. Для ответов ИИ должен работать OpenCode.
- При перезапуске туннеля внешний адрес меняется; отправьте новую ссылку.
- У Cloudflare Quick Tunnels нет гарантии доступности. Аккаунт Cloudflare для этого режима не нужен.
- Трафик проходит через Cloudflare; сквозного шифрования переписки между участниками нет.
- Quick Tunnels не поддерживают SSE: гости получают обновления короткими запросами примерно раз в секунду.
- Если все закрыли чат, агенты автоматически останавливаются после периода отсутствия участников. Для локальных страниц это примерно 45–50 секунд, для гостевых возможна дополнительная задержка до 15 секунд.

## Как всё остановить

| Что остановить | Как |
| --- | --- |
| Только ИИ | Кнопка **«СТОП»** в локальном чате владельца |
| Только доступ из интернета | Ctrl+C в терминале туннеля либо `node stop-sharing.mjs`; на Windows также `stop-sharing.cmd` |
| Сам сервер чата | Ctrl+C в терминале с `npm start` |

Остановка внешнего доступа не выключает локальный сервер. Остановка ИИ не отключает вход гостей.

## Личные данные и файлы, которые нельзя публиковать

Эти файлы **не входят в репозиторий** благодаря `.gitignore` и создаются при использовании:

| Файл | Содержимое |
| --- | --- |
| `conversation.json` | Вся сохранённая переписка, включая сообщения людей |
| `share-private.json` | Секрет приглашения |
| `share-link.txt` | Полная действующая ссылка-приглашение |
| `share-runtime.json` | Локальные идентификаторы процессов туннеля |
| `*.log` | Локальные журналы, которые могут содержать ссылки и ошибки |
| `tools/` | Локально скачанные исполняемые файлы |

Данные авторизации OpenCode читаются сервером из локальной регистрации сервиса. Они **не копируются в проект** и не передаются в браузер. Гостевой шлюз не открывает API OpenCode и не пересылает гостям управляющий токен владельца. Инструменты у ИИ-сессий запрещены.

Любой обладатель действующего приглашения может прочитать всю историю этого чата. Не храните здесь пароли, ключи API и чувствительные личные данные.

### Как отозвать приглашения

1. Остановите внешний доступ.
2. Сохраните новый случайный код:

   ```powershell
   node scripts/rotate-invite.mjs
   ```

3. Запустите туннель заново и отправьте новую ссылку.

Скрипт заменяет только секрет приглашения; переписку не удаляет. Перезапуск шлюза завершает прежние гостевые сессии.

## Настройки для разработчиков

Переменные окружения необязательны:

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `4317` | Порт основного сервера |
| `OPENCODE_SERVICE_FILE` | `~/.local/state/opencode/service.json` | Путь к регистрации локального сервиса OpenCode |
| `OPENCODE_SESSION_ID` | Не задана при самостоятельном запуске | ID сессии OpenCode, модель которой используют новые агенты |
| `CHAT_HISTORY_FILE` | `conversation.json` в папке проекта | Другой путь для сохранения истории |

Готовый туннель и `.cmd`-команды рассчитаны на основной порт `4317` и шлюз `4318`. Если меняете порт основного сервера, нужно также изменить адрес в `share.mjs` и `share-gateway.mjs`.

## Проверки

```powershell
npm test
```

Или:

```powershell
node --test test.mjs share.test.mjs
```

Тесты используют временные серверы и поддельный API OpenCode. Они **не обращаются к модели, не расходуют её лимиты и не запускают публичный туннель**. Проверяются отдельные сессии, отправка сообщений, остановка и возобновление, приглашения, разделение прав, CSRF, ограничение частоты и выход гостей.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| `node` / `npm` не найдены | Установите Node.js 22+ и откройте терминал заново |
| PowerShell запрещает `.ps1` | Используйте `.cmd` или `node server.mjs`; менять политику безопасности не требуется |
| `EADDRINUSE` | Возможно, сервер уже запущен. Откройте локальную ссылку; не запускайте второй экземпляр |
| Интерфейс есть, агенты не отвечают | Работает ли сервис OpenCode, настроена ли доступная модель по умолчанию, остались ли лимиты |
| Ошибка чтения `service.json` | Проверьте запуск сервиса OpenCode и путь `OPENCODE_SERVICE_FILE` |
| Друг не может открыть `127.0.0.1` | Это адрес его собственного компьютера. Ему нужна HTTPS-ссылка из `share-link.txt` |
| Друг просит код | Отправьте полную ссылку с `#invite=...` или локальный `inviteCode`, не публикуя его |
| Старая внешняя ссылка не открывается | Убедитесь, что работают основной сервер и туннель, проверьте актуальный `share-link.txt` |
| Нет `cloudflared.exe` | Выполните `npm run setup:share` |
| Не удалось скачать cloudflared | Используйте официальный релиз и ручную установку с проверкой контрольной суммы |

## Структура проекта

```text
public/                       Интерфейс чата и вход гостей
scripts/install-cloudflared.mjs Безопасная установка туннеля на Windows x64
scripts/rotate-invite.mjs      Новый случайный код приглашения
server.mjs                    Сессии ИИ, история и локальный API
share-gateway.mjs             Изолированный гостевой шлюз
share.mjs                     Запуск шлюза и Cloudflare Tunnel
stop-sharing.mjs              Отключение внешнего доступа на Windows
start.cmd / share.cmd         Запуск на Windows
test.mjs / share.test.mjs      Автоматические тесты
```
